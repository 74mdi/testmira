Welcome to **testmira**. This is a minimal dark blog built with [Astro](https://astro.build), designed for clarity and focus.

## What is this?

A blog template inspired by Claude's clean aesthetic — warm dark tones, readable typography, and zero distractions.

## Features

- Write posts in **Markdown** or **MDX**
- Embed raw HTML directly in your posts
- Deploy to **Cloudflare Pages** in minutes
- Fast static site, zero JavaScript by default

## Try some HTML

<div style="background: #242424; border: 1px solid #2a2a2a; border-radius: 8px; padding: 1.5rem; margin: 1.5rem 0;">
  <h3 style="color: #d4a574; margin-bottom: 0.5rem;">Custom Card</h3>
  <p style="color: #a8a29e; margin: 0;">This is embedded HTML inside a Markdown post. You can use this for callouts, custom layouts, or anything you need.</p>
</div>

## Code blocks work too

```javascript
const blog = {
  name: "testmira",
  theme: "dark",
  vibes: "minimal"
};
```

Start writing your own posts in `src/content/blog/`. Happy blogging.
